# 书架 · 舒适阅读

两部历史学术著作的完整中译，以本地阅读器呈现，GitHub Pages 托管。

## 使用

访问 https://xuanlanxingkongxia.github.io/books/ 即可选择书籍阅读。

- 每本书都有独立阅读页：目录、四种主题（羊皮纸/白/护眼绿/暗）、字号调节、全书检索、阅读进度记忆。
- 字体（霞鹜文楷）随仓库附带，离线可用。
- 快捷键：`←` `→` 翻章，`s` 检索，`t` 目录。

## 声明

译本为个人学习、研究用途的业余试译，仅供阅读参考；引文原典核验工作仍在进行（译文内以〔已核〕〔待核〕标注）。如版权方要求，相关译本将立即撤下。

## 本地重新生成

各书 `阅读器/` 内含 `build_reader.py` 与 `template.html`，修改章节 md 后运行：

```bash
pip install markdown
python build_reader.py
```
